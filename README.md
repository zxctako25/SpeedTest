A lightweight internet speedtest written in Rust. This is an experimental project.

## Installation

Clone the repository:

```bash
git clone https://github.com/zxctako25/speedtest.git
```

Go to the project folder:

```bash
cd speedtest
```

Build and run (requires [Rust](https://www.rust-lang.org/tools/install)):

```bash
cargo run --release
```

The compiled executable will be in `target/release/speedtest.exe`.
